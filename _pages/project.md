# Current Projects

---

## Ongoing Research Projects

### 🔒 HardWhale: Hardware-Isolated Network Security
**Funding:** National Research Foundation (NRF)<br>
**Duration:** 2023-2025<br>
**Description:** Developing hardware-isolated network security enforcement systems for cloud environments using SmartNIC technology.

### ☁️ Hyperion: Container Network Security
**Funding:** Ministry of Science and ICT<br>
**Duration:** 2022-2024<br>
**Description:** Building high-performance and secure systems for container networks with hardware-based acceleration.

### 🌐 MUFFLER: Tor Traffic Obfuscation
**Funding:** Collaborative Research Grant<br>
**Duration:** 2024-2026<br>
**Description:** Secure Tor traffic obfuscation with dynamic connection shuffling and splitting mechanisms.
