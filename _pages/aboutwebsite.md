# TNSLab Website

This website is powered by [Jekyll](https://jekyllrb.com) and uses some [Bootstrap](http://www.getbootstrap.com) and [Bootswatch](http://www.bootswatch.com). The site showcases the research activities and achievements of the Trustworthy Networked System Laboratory (TNSLab) at University of Seoul. 

### Website Structure
This website contains the following main sections:

- **Home**: Overview of TNSLab research areas and recent news
- **Member**: Faculty and student information
- **Research**: Detailed description of our research focus areas
- **Project**: Current and ongoing projects
- **Publication**: Academic publications, conference papers, and patents
- **Gallery**: Laboratory photos and events

### Content Management
All pages are written in [markdown](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet) for easy editing, and [Jekyll](https://jekyllrb.com) uses Liquid for the data-driven pages. The publication list, news items, and team members are stored as `.yml` data sheets in the `_data` folder.

### Technical Details
The website is hosted on GitHub Pages and automatically builds using Jekyll when changes are pushed to the repository. The responsive design ensures compatibility across desktop and mobile devices.
