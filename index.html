Welcome to TNSLab.

Our lab focuses on advancing secure networked systems for cloud environments.
Our research areas span high-performance networking systems and hardware-based network/runtime security systems. Currently, we investigate high-performance container networking interfaces leveraging kernel-bypass techniques, and hardware-isolated network security systems built on programmable data planes. We also explore the use of Trusted Execution Environments (TEE) to enable secure workload execution for both containerized and Function-as-a-Service (FaaS) environments.
We welcome motivated students and researchers with a passion for these topics to join us in pushing the boundaries of trustworthy networked systems.

Keyword: Cloud computing, Network security, Programmable data plane, TEE

Research Areas

☁️ Cloud Computing
- High-performance networking for containers
- Container security
- Serverless computing security

🔒 Network Security
- Network intrusion detection and prevention
- SD-WAN and SDN security
- Network traffic obfuscation

🛡️ System Security
- Hardware-based security systems
- Trusted computing environments
- AI-driven attack detection and response
