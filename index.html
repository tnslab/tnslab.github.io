Welcome to TNSLab 🚀

Trustworthy Networked System Laboratory

We are a dynamic research group led by Prof. Myoungsung You in the Department of Electrical and Computer Engineering at the University of Seoul (UOS). Our laboratory focuses on developing trustworthy networked systems that are secure, reliable, and efficient.

Previous Next

Research Areas

Our research spans three core areas:

☁️ Cloud Computing
- Secure and efficient cloud computing systems
- Container technologies and orchestration
- Distributed computing platforms
- Serverless computing security

🔒 Network Security
- Network intrusion detection and prevention
- Secure communication protocols
- SD-WAN and SDN security
- Network traffic analysis and monitoring

🛡️ System Security
- Hardware-based security solutions
- Trusted computing environments
- System-level attack detection
- Security policy enforcement

Recent Achievements

  • 🏆 IEEE INFOCOM 2025: MUFFLER paper accepted (top-tier networking conference)
  • 📝 IEEE TCC 2024: Hyperion paper published in premier cloud computing journal
  • 🔬 IEEE ICDCS 2024: HardWhale paper accepted at leading distributed systems conference
  • 💡 US Patents: Multiple patents granted in network security and container technologies
