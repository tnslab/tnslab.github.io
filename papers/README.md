# TNSLab Papers Directory

This directory contains PDF files of our research papers and publications.

## File Naming Convention

Please use the following naming convention when adding new PDF files:

### Format: `[paper_name]_[venue][year].pdf`

### Examples:
- `muffler_infocom2025.pdf`
- `hyperion_tcc2024.pdf`
- `cryonics_socc2023.pdf`
- `container_security_kics2022.pdf`

## How to Add New Papers

1. Place the PDF file in this directory (`/papers/`)
2. Update the corresponding entry in `/_pages/publications.md`
3. Add the PDF link using the Jekyll format:
   ```
   [PDF]({{ site.url }}{{ site.baseurl }}/papers/filename.pdf)
   ```
